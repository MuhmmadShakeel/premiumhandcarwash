# Premium Hand Car Wash LLC

A responsive multi-page website rebuilt with React, Vite, Tailwind CSS and AOS.

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

Business content is centralized in `src/data/site.js`; shared UI lives in `src/components`, and route-level views live in `src/pages`.
